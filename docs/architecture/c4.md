# C4 diagrams

The shapes below are the gameplan. A box is not a running service unless the caption says it is in `compose.yaml` today.

The app sends a Nightshift routing mode. Diagrams below use only those two ids. This is the one map to the model that answers today:

| Lane the app sends | Who calls it | Model that answers today |
| --- | --- | --- |
| `meterless/fast` | Configured. No node in the graph on main calls it | Nemotron 3.5 Super VL 120B A12B (`nvidia/nemotron-3.5-super-vl-120b-a12b`) |
| `meterless/deep` | Investigator, Skeptic rationale, Playbook, Judge | Nemotron 3.5 Super VL 120B A12B (`nvidia/nemotron-3.5-super-vl-120b-a12b`) |

Super VL answers both because it is the faster lane as well as the stronger one. Lightning 30B A3B is a second lane configured in Nightshift. It is not what the app sends. No `meterless/auto` in the demo. Watchers and Exposure are SQL. The Skeptic's counter-checks are SQL. Its rationale uses `meterless/deep`.

## System context

The insurer analyst is the person in the demo. Citizens are named in the business-model slide and are not a second system here. Outbound delivery (mail, webhook, or something else) is not chosen, so it is not drawn. Nothing leaves until the analyst approves.

```mermaid
C4Context
title System context for FloodSense EU

Person(analyst, "Insurer analyst", "Reviews the cited chain and approves any outbound action")

System(floodsense, "FloodSense EU", "Explains why a place is at risk, with citations")

System_Ext(zetaris, "Zetaris", "Only data path for the agents")
System_Ext(nightshift, "Meterless Nightshift", "All LLM calls, on meterless/fast and meterless/deep")
System_Ext(sources, "Public sources", "Copernicus EMS, GloFAS, gauges, OSM, and others")

Rel(analyst, floodsense, "Uses")
Rel(floodsense, zetaris, "Reads", "SQL")
Rel(floodsense, nightshift, "Calls models", "HTTPS")
Rel(zetaris, sources, "Federates")
```

## Containers

`python tasks.py up` starts the API, the agent runtime, the engines sidecar, and the UI in Compose project `floodsense-app`. pgvector (`rag`) and Redis (`cache`) are optional profiles. Ingestion is scripts and seed content, not a Compose service. The engines sidecar is in `compose.yaml`. Compose sets `ENGINES_URL=http://engines:8300` on the agents service. The agents package does not call that URL yet. On the host the published port is `127.0.0.1:8300`.

Agents do not read public sources themselves, and this diagram does not give them a direct read of pgvector. The gameplan's working assumption that agents might query pgvector, with that Postgres also registered in Zetaris, is unverified (Urvashi). Whether the semantic cache uses the Redis profile is Ayush's v0.12.0 choice, not drawn as a fact.

```mermaid
C4Container
title Containers for FloodSense EU

Person(analyst, "Insurer analyst", "Reviews the cited chain and approves any outbound action")

System_Boundary(floodsense, "FloodSense EU") {
  Container(ui, "Web UI", "React, TypeScript, Vite", "Map, causal chain, evidence drawer, approval")
  Container(api, "API", "FastAPI", "Runs, SSE, and approval. Proxies the agent runtime")
  Container(agents, "Agent runtime", "Python, LangGraph", "Watchers through Judge, then the human interrupt")
  Container(engines, "Engines sidecar", "Node.js 22.18", "H-MEM and World Model. In compose.yaml")
  Container(ingestion, "Ingestion", "Python scripts", "Stage sources and seed content. Not an agent data path")
  ContainerDb(pgvector, "pgvector", "Postgres", "Optional rag profile for document chunks")
  ContainerDb(redis, "Redis", "Redis", "Optional cache profile. No password, loopback only")
}

System_Ext(zetaris, "Zetaris", "Only data path for the agents")
System_Ext(nightshift, "Meterless Nightshift", "All LLM calls, on meterless/fast and meterless/deep")
System_Ext(sources, "Public sources", "Copernicus EMS, GloFAS, gauges, OSM, and others")

Rel(analyst, ui, "Uses")
Rel(ui, api, "Reads runs", "JSON, SSE")
Rel(api, agents, "Starts a run")
Rel(agents, zetaris, "Reads", "SQL")
Rel(agents, nightshift, "Calls models", "HTTPS")
Rel(agents, engines, "ENGINES_URL is set", "No client in the package yet")
Rel(ingestion, zetaris, "Migrations", "zetaris-sync")
Rel(zetaris, sources, "Federates")
```

## Agent graph

`build_graph()` in `agents/floodsense_agents/graph.py` compiles this graph, with a scope gate before Watchers. The Judge scores claims and does not approve them. The human is the final judge, before any outbound action. A Skeptic revise edge goes back to the Investigator, at most three rounds. Lane names in the diagram are `meterless/fast` and `meterless/deep`. The model that answers today is the table at the top of this page.

```mermaid
C4Component
title Agent graph

Person(analyst, "Insurer analyst", "Final judge of any outbound action")

Container_Boundary(agents, "Agent runtime") {
  Component(watchers, "Watchers", "LangGraph", "SQL on hazard_timeline")
  Component(investigator, "Investigator", "LangGraph", "Cited causal chain. meterless/deep")
  Component(skeptic, "Skeptic", "LangGraph", "At most 3 SQL counter-checks. Rationale on meterless/deep")
  Component(exposure, "Exposure", "LangGraph", "Deterministic exposure SQL")
  Component(playbook, "Playbook", "LangGraph", "Actions that cite evidence. meterless/deep")
  Component(judge, "Judge", "LangGraph", "Scores claims. Does not approve. meterless/deep")
  Component(hitl, "HITL", "LangGraph interrupt", "Approve, edit, or reject")
}

System_Ext(zetaris, "Zetaris", "Only data path")
System_Ext(nightshift, "Nightshift", "meterless/fast and meterless/deep")

Rel(watchers, investigator, "Hands off")
Rel(investigator, skeptic, "Claims")
Rel(skeptic, investigator, "Revise, at most 3 rounds")
Rel(skeptic, exposure, "Continues")
Rel(exposure, playbook, "Exposure")
Rel(playbook, judge, "Draft actions")
Rel(judge, hitl, "Scores")
Rel(hitl, analyst, "Waits for a decision")
Rel(investigator, nightshift, "meterless/deep")
Rel(skeptic, nightshift, "meterless/deep")
Rel(playbook, nightshift, "meterless/deep")
Rel(judge, nightshift, "meterless/deep")
Rel(investigator, zetaris, "SQL")
Rel(skeptic, zetaris, "Counter-check SQL")
Rel(exposure, zetaris, "SQL")
```
